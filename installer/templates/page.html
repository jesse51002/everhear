Voice for Minecraft @@VFG_MC_VERSION@@

This server listens to what you say. Three steps, a couple of minutes. Speech is turned into text on your own computer; no audio ever leaves it.

  1. Download the installer

    Windows

    Download for Windows

    If the browser asks, choose Keep. If Windows says “Windows protected your PC”, click More info, then Run anyway.

    Or skip the warning (and step 2), or if Windows will not run it at all: open PowerShell from the Start menu and paste this.

    @@VFG_PS_COMMAND@@

    Mac or Linux

    Download for Mac / Linux

  2. Run it

    Windows: double-click vfg-install.cmd in your Downloads.

    Mac or Linux: open Terminal and run

    bash ~/Downloads/vfg-install.sh

    You need Minecraft Java Edition, and its launcher opened at least once. Close the launcher first; if it is open, the installer waits for you to close it. Your other installations and mods are not touched.

  3. Play

    Open the Minecraft launcher, pick VFG @@VFG_MC_VERSION@@ next to the Play button, and press Play. Then Multiplayer → VFG → Join Server.

    @@VFG_SERVER_ADDRESS@@

    That is the server address, if you would rather add it yourself.

    In the game, press K to pick your microphone. M mutes. The first start downloads the speech engine in the background; the mic icon in the corner shows its progress.

This link works until @@VFG_EXPIRES_TEXT@@. Each time the server starts it gets a new address and you get a new link: run the new installer and it updates everything, keeping your mic and settings.

Keep this link among friends: the installer carries the key that lets the mod talk to the server.
